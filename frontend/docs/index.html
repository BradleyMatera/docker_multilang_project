🚀 Docker Multi-Language Showcase

Explore how different programming languages print a hello-world message with the current date and time. Modern, responsive, and visually bold.

CCompiled systems language. Prints date/time.
#include <stdio.h>
#include <time.h>
int main() {
  time_t t;
  time(&t);
  printf("Hello ASL! The date is: %s", ctime(&t));
  return 0;
}
GoModern compiled language. Prints date/time.
package main
import (
  "fmt"
  "time"
)
func main() {
  fmt.Println("Hello ASL! The date is:", time.Now())
}
JavaPopular OOP language. Prints date/time.
import java.time.LocalDateTime;
import java.time.format.DateTimeFormatter;
public class Hello {
  public static void main(String[] args) {
    DateTimeFormatter dtf = DateTimeFormatter.ofPattern("yyyy/MM/dd HH:mm:ss");
    LocalDateTime now = LocalDateTime.now();
    System.out.println("Hello ASL! The date is: " + dtf.format(now));
  }
}
