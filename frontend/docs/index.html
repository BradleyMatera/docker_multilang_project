Language Showcase

Containerized demos spanning seven runtimes.

Each container boots its language of choice, prints a time-stamped greeting, and illustrates how Docker Compose orchestrates a consistent developer experience.

C
Procedural

Systems programming classic with explicit compilation.

#include <stdio.h> #include <time.h> int main() { time_t t; time(&t); printf("Hello ASL! The date is: %s", ctime(&t)); return 0; }
Go
Compiled

Modern compiled language built for concurrency and tooling.

package main import ( "fmt" "time" ) func main() { fmt.Println("Hello ASL! The date is:", time.Now()) }
Java
OOP

Object-oriented, JVM powered, enterprise friendly.

import java.time.LocalDateTime; import java.time.format.DateTimeFormatter; public class Hello { public static void main(String[] args) { DateTimeFormatter dtf = DateTimeFormatter.ofPattern("yyyy/MM/dd HH:mm:ss"); LocalDateTime now = LocalDateTime.now(); System.out.println("Hello ASL! The date is: " + dtf.format(now)); } }
Node.js
Event-driven

JavaScript runtime with vast package ecosystem.

console.log("Hello ASL! The date is: " + new Date().toLocaleString());
PHP
Scripting

Battle-tested server-side scripting for the web.

<?php echo "Hello ASL! The date is: " . date('Y-m-d H:i:s') . "\n"; ?>
Python
Multi-paradigm

Readable powerhouse for data, scripting, and web.

from datetime import datetime print(f"Hello ASL! The date is: {datetime.now()}")
Ruby
Object-oriented

Expressive language focused on developer happiness.

puts "Hello ASL! The date is: #{Time.now}"

Deployment Story

From container orchestration to static hosting.

The project marries runtime parity across containers with a modern static site workflow. Follow the path to get everything running locally and hosted globally.

1

Container orchestration

Docker Compose spins up C, Go, Java, Node.js, PHP, Python, and Ruby services inside a shared bridge network.

2

Modern frontend rebuild

Next.js 16 with Bun compiles the premium UI, leveraging NextUI theming and Tailwind utilities for polish.

3

Static export

next export produces the docs/ bundle with .nojekyll, ready for GitHub Pages hosting.

4

Continuous deployment

GitHub Actions (optional) can run lint, tests, and bun run build:pages on every push to main.
